Connected eSSL Biometric Devices

Live integration with 4 eSSL F18 + F12 fingerprint/card devices via Port 4370

Network Integration Details:

The system connects to all 4 eSSL F18+F12 devices using the standalone ZKTeco protocol over Port 4370 (TCP & UDP fallback). Make sure the PC running this dashboard is on the same office local network (172.16.0.0/24) or connected via office VPN.

Duplication is prevented at the database level by unique constraint on (employee_id, timestamp). You can sync repeatedly without creating redundant punch records.
